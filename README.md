# Assignment #4: Forms and Validation

**Student:** Sultanov Abilkaiyr  
**Group:** SE-2529  

## Overview
This project demonstrates the creation of web forms using HTML5 and Bootstrap 5, featuring built-in HTML5 validation and Bootstrap custom feedback styling.

## Structure
- `index.html` — Main landing page with navigation bar.
- `part1.html` — Basic HTML form with HTML5 built-in validation attributes.
- `part2.html` — Styled contact form using Bootstrap grid, utility classes, and validation styles.
- `part3.html` — Advanced registration form with responsive layout, custom password verification, and complete form control styling.

## Technologies Used
- HTML5
- Bootstrap 5 (via CDN)
- JavaScript (Bootstrap Client-side Validation)
